      How to play

      1. Install GTA: Vice City for PC (Steam, Rockstar Launcher or discs). Game files aren’t provided here.
      2. Drop the game folder or a .zip of it onto “Game files (PC)”, or use its buttons.
      3. Wait a few minutes until it says “Ready to play”.
      4. Press “Start to play” and wait for the game to load.
      5. You only need to do this once: the game stays stored in this browser and works offline.
      VIDEO & PERFORMANCE

      Game Settings

      Settings are saved in this browser and applied the next time the game starts. Lower resolution and draw distance can reduce graphics workload. FPS limiting may reduce load when the game would otherwise run faster.
